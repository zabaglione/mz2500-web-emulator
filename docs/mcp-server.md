# MZ-2500 MCPサーバー — AIからエミュレータを操作する

Web版と同じWASMコアをNode.jsでヘッドレスにホストし、
[Model Context Protocol](https://modelcontextprotocol.io/) のツールとして公開するサーバー。
AIエージェント（Claude Code等）が実機さながらにキーを打ち、画面を読み、音を聴き、
メモリを覗きながらBASICプログラミングできる。ソースは [`mcp/`](../mcp/)。

## Web版（GitHub Pages）との関係

| | Web版エミュレータ | MCPサーバー |
|---|---|---|
| 動く場所 | ブラウザ（GitHub Pagesの静的配信で完結） | 利用者のマシン上のNode.jsプロセス |
| 操作するのは | 人間（キーボード・パッド・マウス） | AIエージェント（MCPツール呼び出し） |
| コア | 同一のWASMコア（`mz2500w.wasm`） | 同一のWASMコア（Nodeでロード） |
| 時間の進み方 | 実時間（60fps描画） | **ツール駆動**（呼び出しの間は停止。決定的で実時間より高速） |

MCPサーバーはstdioで動くローカルプロセスなので、**GitHub Pages上では動かない**。
Pagesで公開されるのは従来どおりブラウザ内エミュレータだけで、`mcp/` のコードは
リポジトリに同梱される不活性なソースにすぎない（Web側のバンドルはMCPを一切参照しない）。

## セットアップ

```bash
# 1. WASMコアをビルド（要 emscripten）
tools/build_wasm.sh

# 2. サーバーをビルド
cd mcp && npm install && npm run build
```

Claude Code等への登録例（`.mcp.json`）:

```json
{
  "mcpServers": {
    "mz2500": {
      "command": "node",
      "args": [
        "/path/to/web_emulator/mcp/dist/index.js",
        "--rom-dir", "/path/to/roms/mz2500",
        "--disk-a", "/path/to/basic-m25.d88",
        "--workdir", "/path/to/mz2500-work"
      ]
    }
  }
}
```

**ROM・BASICディスクは同梱していない**。利用者所有のファイルをパスで指定する
（`ipl.rom`/`cg.rom`/`kanji.rom`/`dict.rom` とブートディスクのD88）。
ROM無しでも、同梱デモディスクのダミーIPLブートだけは動く。

## できること（ツール群の概要）

- **入力**: 文字列打鍵（SHIFT自動）、名前指定キー（BREAK等・修飾・長押し）、ジョイスティック
- **観察**: テキストVRAMの文字列読取、640×400スクリーンショット、指定文字列の出現待ち
- **音**: YM2203レジスタの解読（FM/SSG各chの音名・キーオン・音量、BEEP）、WAV録音
- **内部**: メモリ読み書き（CPU空間/物理）、CPUレジスタ・バンク・FDC等の状態取得
- **メディア**: D88ホットスワップ、ドライブ内容のD88書き出し（SAVEした成果物の回収）

ツールの正確な一覧と引数は [`mcp/README.md`](../mcp/README.md) を参照。

## 観戦ビュー（人間がAIの操作を見る）

サーバー起動中に `http://127.0.0.1:8425/` をブラウザで開くと、AIの操作を観戦できる。
画面・音声・YM2203の発音状態がフレーム番号で同期して届き、ブラウザ側がバッファして
実機速度（約55.5fps）で等速再生する。マシンはツール駆動のまま全速で進むため、
表示は少し遅れて追いかけ、追いつくと「AIの操作待ち」になる。

- ポートは `--spectate-port N`（環境変数 `MZ2500_SPECTATE_PORT`）で変更、`0` で完全無効
- 観戦者が誰もいない間はフレーム生成ごと停止し、オーバーヘッドはない
- 127.0.0.1バインドに加えOrigin/Hostヘッダを検証（DNSリバインディング対策）。リモート公開は想定しない

### ポートの割り当て

観戦ビューとローカルWebプレビューは**同時に動く別々のサーバー**なので、必ず別番号にする。
本プロジェクトでは次のとおり割り当てている：

| ポート | 用途 | 変更方法 |
|---|---|---|
| **8425** | 観戦ビュー（MCPサーバーが自動で開く） | `--spectate-port N` / `MZ2500_SPECTATE_PORT`（`0`で無効） |
| **8500** | Web版 `web/dist` をローカルの静的サーバーで試すとき（開発用） | 静的サーバー側の起動引数 |

観戦ビューは8425が塞がっていると8426、8427…と空きポートへ自動フォールバックし、
ビューアのセッション一覧から各セッションへ1クリックで移動できる（人間の手順は
「8425を開くだけ」で不変）。Webプレビュー側（8500）は静的サーバーの仕様に従う。

### よくある罠: Claude.app が1つでもサーバーが2本立つ

Claude Desktop のグローバル設定（`claude_desktop_config.json`）にこのサーバーを
登録すると、アプリ1つでも Desktopチャット側と Claude Code セッション側の
**2つのクライアント接続からそれぞれ1プロセス**が起動する。先に起動した方
（多くは誰も操作しないDesktop側）が8425を取り、観戦ビューには起動直後で
止まった画面が映り続ける。グローバル設定はMZ-2500と無関係な会話でも常時
サーバーを起動・参照しようとするので、**登録はグローバルではなくプロジェクト内の
`.mcp.json`（プロジェクトスコープ）に作るのが正解**。
詳細は [`mcp/README.md`](../mcp/README.md) の観戦ビュー節を参照。

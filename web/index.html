ヘルプ
デモゲームの遊び方

SPACE = 決定 / ジャンプ ・ カーソルキー = 移動 ・ Z = ダッシュ
ゲームパッド: A / × = トリガ1 ・ B / ○ = トリガ2 ・ 十字キーまたは左スティック = 移動 （割り当ては「ゲームパッドのボタン割り当て」で変更できます）

NEKO CAN RUN の初期設定はトリガ2 = ジャンプ、トリガ1 = ダッシュです。 タイトル画面の CONFIG で入れ替えられます。

同梱の NEKO CAN RUN デモ版（WORLD 1）は動作検証を兼ねたサンプルです。 デモ版・製品版（有償・全4ワールド）は BOOTH（ザバイオーネ研究室） にて配布中。

使い方

画面下の KEYBOARD で画面上のキーボードを開閉できます。 SHIFT・CTRL・GRAPH・カナ・LOCK は押すと固定され、もう一度押すと戻ります。 そのほかのキーは押している間だけ入力され、実キーボードとも同時に使えます。

画面へ D88 をドロップすると FD1 に入れて起動します。 FDDベイへのドロップや交換アイコンでは、リセットせずディスクを交換できます。 複数ボリューム入り D88 は自動分割され、ドライブ内の選択欄で切り替えられます。 ディスクはこのブラウザ内に保存され、外部には送信されません。

各操作の短い説明は、ボタンへマウスを重ねるか、キーボードでフォーカスすると表示されます。

ハードウェア構成（拡張ボード）

実機のオプションボード相当。変更は保存され、RAM/GRAMはIPL後に反映されます。 同梱デモは既定構成（すべてON）を前提としています。

キーボード

テンキーで8方向移動するソフトを、テンキーの無いキーボードで遊ぶための補正です。 ドライブ横の「テンキー」ボタンで入切でき、設定は保存されます。



マウス

画面をクリックすると捕捉します。Esc で解放（この Esc は MZ には送りません）。 捕捉中は Option（Alt）キーが MZ の ESC になります （捕捉中はブラウザが Esc を横取りするため MZ に届かず、画面上のキーボードもクリックできないため）。
MZ-1X10 は SIO チャンネルB につながり、OPN ポートA の b3 で切り替わります。
左クリック＝MZ-1X10 のボタン1、右クリック＝ボタン2です（中央ボタンは未対応）。 捕捉中は右クリックしてもブラウザの右クリックメニューは出ません。

CMT data recorder

画面下のボイスレコーダでWAVテープを操作します。カセット窓の下にある アイコンは、左からWAV読込、再挿入、5分のブランク作成、ライトプロテクト、WAV保存です。

データトラックのパルス幅を保ったまま読み書きします。MIC・EARとRECキーは 実機のアナログ音声トラック用で、現在は外観と状態表示のみです。

SASI hard disk (MZ-1E30)

Mount a raw HDF image. The target implements SASI bus phases, automatic A4h ACK handshakes, six-byte commands, read/write/format, sense, and the optional A8h/A9h BIOS ROM window. Images stay in this browser.

Parallel printer (FEh/FFh)

Centronics-compatible raw capture. STB, PRIM, STA/ACK, BUSY, and the printer interrupt are timed by the machine core. Save the byte stream as a .prn file; no character set or printer commands are assumed.

POWER OFF

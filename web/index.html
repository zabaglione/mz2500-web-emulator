ハードウェア構成（拡張ボード）

実機のオプションボード相当。変更は保存され、RAM/GRAMはRESET後に反映されます。 同梱デモは既定構成（すべてON）を前提としています。



キーボード

テンキーで8方向移動するソフトを、テンキーの無いキーボードで遊ぶための補正です。 ドライブ横の「テンキー」ボタンで入切でき、設定は保存されます。



マウス

画面をクリックすると捕捉します。Esc で解放（この Esc は MZ には送りません）。 捕捉中は Option（Alt）キーが MZ の ESC になります （捕捉中はブラウザが Esc を横取りするため MZ に届かず、画面上のキーボードもクリックできないため）。
MZ-1X10 は SIO チャンネルB につながり、OPN ポートA の b3 で切り替わります。
左クリック＝MZ-1X10 のボタン1、右クリック＝ボタン2です（中央ボタンは未対応）。 捕捉中は右クリックしてもブラウザの右クリックメニューは出ません。

ゲームパッドのボタン割り当て

実機のジョイスティックは2ボタン（トリガ1・トリガ2）です。どのパッドボタンを どちらのトリガにするかを選べます。設定は保存されます。
NEKO CAN RUN の初期設定はトリガ2 = ジャンプ、トリガ1 = ダッシュで、 タイトル画面の CONFIG で入れ替えられます。

ROM設定（上級者向け・任意）

実機からご自身で吸い出した ROM を登録できます。ファイルはこのブラウザ内にのみ保存され、 どこにも送信されません。ROM が無くても同梱ゲームは完全動作します。

NEKO CAN RUN デモ版（WORLD 1）を起動します（音が出ます）

●FD1 - ●FD2 (empty)
POWER OFF

SPACE = 決定 / ジャンプ ・ カーソルキー = 移動 ・ Z = ダッシュ
ゲームパッド: A / × = トリガ1 ・ B / ○ = トリガ2 ・ 十字キーまたは左スティック = 移動 （割り当ては左の「ゲームパッドのボタン割り当て」で変更できます）
NEKO CAN RUN の初期設定はトリガ2 = ジャンプ、トリガ1 = ダッシュです。 タイトル画面の CONFIG で入れ替えられます。

ドライブ横の「キーボード」ボタンで画面上のキーボードを開閉できます（実機と同じキー配列）。 GRAPH・カナ・LOCK・変換・無変換・HELP・COPY・HOME/CLR・BREAK・アルゴ、テンキーの * / など、 パソコンのキーボードに無いキーはここから押せます。開閉の状態は保存されます。
SHIFT・CTRL・GRAPH・カナ・LOCK は押すと固定され（もう一度押すと戻ります）、 片手・マウスだけでも SHIFT + BREAK や GRAPH + キーのような同時押しができます。 それ以外のキーは押している間だけ入り、押したまま指やポインタが外れると離した扱いになります。 画面上のキーボードとパソコンのキーボードは同時に使えます。

画面へ D88 をドロップ = FD1 に入れて起動（IPLPRO ブートのみ）。 各ドライブの「入替」やドライブ枠へのドロップ = リセットせずディスク交換。 複数ボリューム入り D88 は自動分割され、ドライブ横のプルダウンで枚を切り替えられます（2枚組対応）。 入れたディスクはこのブラウザ内に保存され（外部送信なし）、次回もそのまま起動します。⏏ で保存を消去。

同梱の NEKO CAN RUN デモ版（WORLD 1）は動作検証を兼ねたサンプルです。 デモ版・製品版（有償・全4ワールド）は BOOTH（ザバイオーネ研究室） にて配布中。
